FAQ

Questions.

Windows says "Windows protected your PC". Is that normal?

Yes. Windows shows this for new apps that are not signed with a paid certificate. Click More info, then Run anyway. You only need to do this once. The full source code is public if you want to review it.

Do I need to install anything?

No. OG Checker is a single file. It uses the WebView2 component that already ships with Windows 10 and 11.

What do 3L, 4L and 4C mean?

The number is the length and the letter is the type: L for letters only, N for numbers only, C for mixed characters. Names with three characters, or four letters, are tagged OG.

If a name shows as available, can I always claim it?

Usually, but not always. Platforms sometimes reserve names, block certain words, or hold names from banned accounts. Instagram and TikTok are the least predictable. Anything that cannot be confirmed is shown as Unknown, never as available.

Is there a Mac version?

Not as a download yet. Mac and Linux users can run it from the source code with Python.
